Lotes de um Leilão (Auction Lots)

 Version v0.0.1
Status Working
Link github.com/pedrowsxz/lotes-leilao
Stack FastAPI, SQLite, React, TypeScript, React Router, pytest, Vitest, React Testing Library
Description

Full-stack app to register and browse auction lots. REST API with validation (400/422), sorting and price filtering done in SQL through a fixed whitelist of columns (no query-string interpolation), UI state synced to the URL so filtered views are shareable, a lot detail page, and automated tests on both backend and frontend. The backend was rewritten from Express to FastAPI keeping the exact same HTTP contract, so the frontend needed no changes.
